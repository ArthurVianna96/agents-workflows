# Contributing

Keep this repository portable, focused, and safe to publish.

- Write in neutral, agent- and provider-independent language. Do not require a specific model, product, plugin, or command-line tool.
- Keep each skill focused on one repeatable outcome. State the required context, expected output, and completion criteria.
- Make outputs explicit enough for the next role or session to use without guessing.
- Attribute every catalog entry: include its upstream URL, author or organization, source/license note, and installation guidance. Link upstream instead of copying third-party files.
- Never add secrets, customer data, employer-specific material, private repository details, or credentials.

Before proposing a change, read the affected file as a standalone artifact, check its links, and make sure it fits the shared handoff contract.
